# vimrc for Vim

Vim configuration (Vimscript + [vim-plug](https://github.com/junegunn/vim-plug)).
`vimrc` bootstraps vim-plug and sources every `settings/*.plug` and
`settings/*.vim` file.

The Neovim configuration has migrated to a Lua/[lazy.nvim](https://github.com/folke/lazy.nvim)
setup on the **`neovim-lua-migration`** branch.

Other branches hold environment-specific variants (Windows/Linux/Rails/Go/CLISP/etc.).
